type: llm
---

PASS if the executable constructs a provider hierarchy with environment overrides before application defaults, uses native library configuration readers where available, and keeps adapters for unsupported types in focused executable-local extensions. Application-specific mount paths and other deployment defaults belong to the executable; adapters read relative keys from a scoped reader without extra default/path arguments. Serve assembles dependencies and lifecycle rather than parsing TLS files or validating configuration. If numeric application duration settings are introduced, their keys include units; upstream reader keys remain unchanged.
FAIL if Serve contains configuration validation guards, adapters embed application mount layouts or demand default/directory arguments alongside a reader, environment overrides lose to application defaults, or a native reader is duplicated without a concrete API gap. Judge the files and call sites together, not exact filenames or local variable names. An existing reloader passed to a transport factory is a runtime dependency and is allowed.
