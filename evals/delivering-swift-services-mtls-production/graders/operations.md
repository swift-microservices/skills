PASS only if renewal is external, publishes chains atomically into stable directories, and preserves key/roots for ordinary renewal. Workloads run TimedCertificateReloader in their service group; directory permissions enforce read-only application access and per-workload isolation. Include issuer outage/expiry alerts, publication errors, serial observation, malformed-file retention and peer rejection of parseable invalid material. Root changes recreate transports; emergency revocation closes active sessions. Require approval before changing deployment and distinguish local checks from rollout evidence. FAIL for individual inode-bound file mounts, promised automatic trust-root reload, implicit deployment, or pretending that container health proves certificate acceptance.
