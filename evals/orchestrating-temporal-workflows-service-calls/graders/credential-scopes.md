PASS if native Temporal worker Configuration(configReader:) consumes the SDK's own scoped keys, while a reusable relative-key reloader adapter is called separately with tls and temporal.tls. Both pairs are primed through TimedCertificateReloader from NIOCertificateReloading before their transports are created and both reloaders are owned exactly once in ServiceGroup. Both outgoing transports use explicit CA roots and full server verification. Executable defaults provide distinct mount paths without extra path/default parameters on the adapters.
FAIL if Temporal shares the service pair, either reloader is optional/unstarted, the SDK reader is manually duplicated, or client verification is disabled. Runtime reloader arguments to security factories are legitimate.
