PASS only if a standard TimedCertificateReloader is primed at startup and run in the service group, supplying native mTLS. External automation owns issuance and atomic chain publication into a stable directory; ordinary renewal preserves key and roots. Startup checks the local chain/key/identity/lifetime. Parse/read/key failures retain the last loaded pair; the answer must acknowledge that the loader does NOT validate expected URI or trust and a parseable invalid replacement can disrupt connections. FAIL for claiming atomic multi-file swaps, automatic identity validation by the reloader, unowned per-update tasks, a custom security state machine, or an application-issued certificate.
